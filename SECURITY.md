# Security Policy

Security fixes are applied to the latest tagged release and the `main` branch.

## Reporting a vulnerability

Please do not open a public issue or include sensitive repository material in a report. Use [GitHub's private vulnerability reporting](https://github.com/SEKKAIE/scourgify/security/advisories/new) and include:

- the affected version or commit;
- a minimal sanitized reproduction;
- the impact and any known mitigation.

I aim to acknowledge complete reports within seven days. Publication and remediation timing will be coordinated with the reporter.

Scourgify inspects repository state, paths, and selected project metadata. Never use real secrets, credentials, private repository contents, or identifying local paths in a public reproduction. Treat scanner snapshots and closeout ledgers as potentially sensitive artifacts.
